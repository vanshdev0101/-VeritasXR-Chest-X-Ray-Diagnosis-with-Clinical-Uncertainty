Pneumonia classification with pathway disagreement as uncertainty

A 4.2M-parameter dual-pathway CNN trained from scratch. Two branches read the same image at different kernel scales; their disagreement is the uncertainty estimate. Everything below runs in your browser — the image never leaves your device and there is no server.

The band is conveyed by its label and icon as well as its colour. Thresholds are the 60th and 85th percentile of entropy on the validation split — a property of this model, not a clinical standard.

Pathway disagreement: — — reported, but not used. This architecture was designed to treat disagreement between its two pathways as the uncertainty signal. Measured against the model's own errors it scores AUROC 0.5046, which is chance, and combining it with entropy makes entropy worse. Both heads are trained on the same labels with the same loss, so they converge toward each other and rarely disagree at all. The number is shown because the negative result is part of the finding.

3 · What each pathway looked at

Class activation maps, computed without gradients: each pathway head is a single linear layer on globally-pooled features, so the map is a weighted sum of feature maps. If the two pathways attend to the same region, they agree; if not, that disagreement is what the uncertainty score measures.
